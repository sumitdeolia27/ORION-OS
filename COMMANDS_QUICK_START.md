# ⚡ QUICK COMMANDS REFERENCE

## 🎯 Most Used Commands

### System Control
```bash
screenshot              # Take screenshot
volume 75               # Set volume to 75%
volume up               # Increase volume
mute                    # Mute system
system info             # Show system specs
```

### File Operations
```bash
open C:\Users           # Open folder
list files C:\Users     # List files
create folder test      # Create folder
copy file.txt C:\       # Copy file
delete old.txt          # Delete file
```

### Process Management
```bash
processes               # List all processes
top processes cpu       # Top by CPU
kill chrome             # Kill process
run notepad            # Start program
```

### Browser & Search
```bash
open browser google.com # Open website
search python tutorial  # Google search
youtube coding          # Search YouTube
```

### AI Commands
```bash
ask ai what is python   # AI chat
analyze image photo.jpg # Analyze image
generate image sunset   # Generate image
```

### Productivity
```bash
add task finish work    # Add task
show tasks              # List tasks
remind me call mom      # Add reminder
calculate 25 * 4        # Calculate
```

## 🎤 Voice Commands

1. Click **🎤 microphone** button
2. Speak your command
3. Wait for recognition (10 seconds)
4. Command executes automatically

**Examples:**
- "Take a screenshot"
- "Open browser and search for Python"
- "Set volume to 50"
- "Show me running processes"

## 📋 How to Use

1. **Open Command Console** in dashboard
2. **Type command** or use voice
3. **Press Enter** or click send
4. **See results** in console
